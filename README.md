A full-featured e-commerce application built with React, Tauri, and Dexie (IndexedDB).
The project includes user shopping flow, admin panel, role-based access, cart & orders, discounts, stock management, and offline-first data handling.

This project is designed to simulate a real-world production-level e-commerce system.

✨ Key Highlights

🔐 Authentication (Login / Register)

👤 User & Admin roles

🛍️ Cart, Wishlist & Checkout flow

📦 Order management

🎯 Discounts (Percentage & Flat)

📉 Stock management

🧑‍💼 Admin panel (Products & Orders)

🌍 Country-based product visibility

💾 Offline-first DB using Dexie (IndexedDB)

🎨 Modern UI using Tailwind + shadcn/ui

🚀 Desktop-ready with Tauri
